CSE

Computer Science and Engineering students already learn programming, data structures and databases. In this training, they use Java to build a complete web application, from the page you see in the browser to the database behind it.

ECE

Electronics and Communication students know circuits, signals and embedded systems. This training adds Java and web skills, so they can build software dashboards and apps that work with devices and hardware.

IT

Information Technology students work with data, networks and web systems. In this training, they learn the full path of an application: the front end with HTML, CSS and JavaScript, the back end with Java and Spring Boot, and the database with MySQL. At the end, they can build and run a real project on their own.
